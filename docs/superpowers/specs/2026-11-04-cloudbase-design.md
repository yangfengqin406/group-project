# CloudBase 课程测试迁移设计

用户已授权启动迁移；交付目标是 Android App 的真实账号、互助、私信、宠物、衣柜和完整小游戏不依赖个人电脑。保留现有 uni-app 页面及 HTTP 协议，避免重写已验收业务。正式上架或备案不是本轮完成标志。

## 选择与边界

直接把 SQLite 放入函数临时磁盘会在实例销毁后丢失；全面改写同步 SQL 为异步文档仓库则会扩大本轮业务风险。因此本次课程小数据集用 CloudBase 私有PG单行JSONB保存版本化逻辑快照，私有云存储保存图片，每个请求恢复独立内存 SQLite 执行原事务规则，再用云端id+version条件UPDATE提交。单状态限制 4 MiB，写冲突有限重算；达到容量或并发瓶颈须改为按业务集合的正式仓库，不能无限扩展此方案。

## 一致性与权限

响应成功必须在持久提交之后。只对明确版本冲突重算；未知提交结果返回服务不可用，不自动重复提交。新增图片先上传后关联，未提交图片进入私有孤儿对象清理流程；删除先撤销读取权限，清理队列在云端保留。所有原表顺序、账号密码哈希、会话、分页密钥、幂等回执均保留。CloudBase 表/对象仅服务端私有REST配置可访问，客户端沿用原鉴权接口。

斗地主每次请求恢复同一版本私有 checkpoint，执行 tick 和命令，再随状态提交；不向客户端暴露完整牌局、令牌或快照。物理函数实例不拥有独立持久牌桌。

## 迁移与验收

先部署虚构测试库，验证跨实例注册/消息/奖励/上传、故障不假成功及重启恢复；再取得源数据库一致快照、图片校验清单和停写边界。目标已有数据时拒绝覆盖，另做增量协调。备份保留，App 在手机切换云端地址重新登录，并以原电脑断网/关机验证后才退役旧入口。2026-11-05原数据已导入并逐条核验，手机App切源与关机验收仍待用户。
