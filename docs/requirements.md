# 已落实的项目需求

## 产品形式与课程约束

uni-app + Vue 3 + JavaScript；手机端微信小程序为主要入口，同时提供可部署 H5。最终必须有老师可访问的 URL 或小程序码。未通过微信审核或前期开发时，用 H5 作为替代方案。固定视角像素卡通广场，不承诺自由视角 3D 或多人实时移动。

## 入口

| 广场房子 | 内容 |
| --- | --- |
| 二手集市 | 出售列表、发布、详情、联系；求购及匹配后续扩展 |
| 找搭子小屋 | 活动计划、规则推荐、邀请与双方确认；技能互助放在这里 |
| 失物招领 | 丢失/拾获、卡片/钥匙/杂物三分类、图片发布、查询、评论/私信、完成状态 |
| 自己的家 | 当前用户资料、我的发布；与底部“我的”同一页面 |

底部栏目固定为广场、消息、我的。消息不是房子。广场占满可用窗口，使用场景内消息和自己的家入口，离开后恢复普通页面底栏。顶部居中的“校园活动”和中心布告栏打开同一只读面板，并可前往既有消息中心；bulletin.list 提供未来三天的虚构校园活动与时间、地点、组织方、参与方式，不表示真实报名或 event 模块已经实现。

广场主画面集中展示四栋建筑、宠物和公告栏；日期、大标题、业务长列表与下方走动操作条不占用场景。点击建筑先让宠物沿步道与支路走到门口，再跳转模块。横竖窗口均响应布局，提供全景和探索视图，不承诺网页强制锁定横屏。

四栋业务房子的门牌改为与屋顶配色呼应的悬挂小木牌，搭子、失物、二手、自己的家分别使用双叶、放大镜、提袋和家图形。西南小路接池边栈台，北侧小路接四空座开放亭；池塘和亭子是场景地点，不增加业务房子。

## “模块有联系”的具体含义

- 一个账号、一个公开个人资料体系；点任何作者名称/头像进入同一个公开主页，能看到该用户各模块的公开发布。自己的家额外展示本人内容和私有设置。
- 二手、失物、搭子和技能互助共用 conversation.open / message.send / message.list。
- 消息保留 contentType 与 contentId，可回到原商品、原计划或原失物。
- 消息中心统一汇总二手、失物和搭子会话，可按来源筛选；失物详情另提供公开评论区。微信订阅只能由用户点击授权，网页端继续以站内通知为准。
- 共用图片上传契约、发布/详情、内容卡片、错误与确认弹窗、收藏和举报。
- 推荐是需求主动找相近需求，用户选择并确认，不自动组队。技能和求购的双向推荐属于第二周。

## 首版必须完成（最终真实 v0.1，不代表本骨架已完成）

像素广场、基础角色操作、建筑入口；搭子发布、筛选、规则推荐；邀请、双方确认、取消、完成；二手和失物的基础发布、查询、联系；技能标签、求助与筛选；个人空间、消息中心、基础留言。真实登录、持久化、权限与 H5 部署是贯通这些功能的必要基础。
